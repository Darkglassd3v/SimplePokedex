# Simple Pokedex

A modern Android application for browsing Pokémon, implementing reactive architectures, asynchronous data handling, and a declarative user interface.

## Technologies Used 

* **Kotlin**
* **Jetpack Compose**
* **Dagger Hilt**
* **UniFlow (Uni-directional Data Flow)**
* **Retrofit & OkHttp**
* **Kotlin Coroutines & Flow**
* **Coil (Coroutines Image Loader)**
* **Room Persistence Library**
* **Jetpack Navigation Compose**
* **Adaptive Navigation Suite**
